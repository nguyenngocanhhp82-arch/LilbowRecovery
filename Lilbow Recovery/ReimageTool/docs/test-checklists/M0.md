# Checklist M0 — Thiết lập môi trường

> **Milestone:** M0 — Tuần 1 (05–11/10/2026)
> **Mục tiêu:** Dựng môi trường phát triển và kiểm thử, tạo repo, cấu hình Antigravity.
> **Người thực hiện:** Nhân viên IT (con người, không phải AI agent).

---

## ✅ Danh sách kiểm tra

### 1. Cài đặt phần mềm trên máy phát triển

- [ ] Cài **Windows ADK** (phiên bản khớp với Windows đang dùng)
  - Tải tại: https://learn.microsoft.com/en-us/windows-hardware/get-started/adk-install
  - Chỉ cần cài **Deployment Tools** + **Windows PE add-on**
- [ ] Cài **Hyper-V**
  - Control Panel → Programs → Turn Windows Features on or off → Hyper-V → OK
  - Hoặc: `Enable-WindowsOptionalFeature -Online -FeatureName Microsoft-Hyper-V-All`
- [ ] Cài **Visual Studio Community 2022** (hoặc 2019)
  - Workload: `.NET desktop development`
  - Đảm bảo chọn `.NET Framework 4.8 targeting pack`
- [ ] Cài **Inno Setup** (từ https://jrsoftware.org/isinfo.php)
- [ ] Cài **Git for Windows**

---

### 2. Dựng VM Hyper-V Generation 2 (UEFI)

> Tham khảo `tools/test-vm/README.md` để biết cài đặt chi tiết.

- [ ] Tạo VM mới: **Generation 2**, RAM 4 GB (hoặc hơn), đĩa 100 GB
- [ ] Trong Settings VM → Security: kiểm tra **Secure Boot** (`Microsoft Windows` template)
- [ ] Đĩa 100 GB, cài Windows 11 sạch
- [ ] Sau khi cài Windows, kiểm tra:
  - C: là phân vùng Windows (nhãn `WINDOWS` hoặc tương đương), NTFS
  - Có phân vùng EFI (FAT32, ~100-500 MB)
- [ ] Tạo đĩa ảo thứ 2 (hoặc phân vùng D: trên cùng đĩa): **NTFS, nhãn `DATA`**, ít nhất 50 GB
- [ ] Tạo file thử: `D:\test\du-lieu.txt` với nội dung bất kỳ
  - Dùng để xác nhận ổ D: không bị động tới sau restore

---

### 3. Cấu hình VM

- [ ] Tắt **BitLocker** trên C: và D: (nếu bật)
  - `manage-bde -status` để kiểm tra
  - BitLocker phải ở trạng thái `Fully Decrypted`
- [ ] Đặt nhãn (label) phân vùng C: và D: rõ ràng (dùng trong job.json)
  - Ví dụ: C: → nhãn `WINDOWS`, D: → nhãn `DATA`
  - PowerShell: `Set-Volume -DriveLetter C -NewFileSystemLabel "WINDOWS"`
- [ ] Ghi chú GUID phân vùng (dùng cho kiểm thử):
  - `Get-Partition -DriveLetter C | Select-Object Guid`
  - `Get-Partition -DriveLetter D | Select-Object Guid`

---

### 4. Snapshot VM

- [ ] Tạo checkpoint (snapshot) VM tên **`sach`** — trạng thái Windows vừa cài sạch, D: có file thử
- [ ] Kiểm tra khôi phục snapshot `sach` thành công
- [ ] Đặt tên checkpoint mô tả rõ ràng, tránh nhầm lẫn

---

### 5. Repo Git

- [ ] Khởi tạo Git trong thư mục `ReimageTool`:
  ```bat
  cd C:\Dev\ReimageTool
  git init
  git add .
  git commit -m "M0: Khung repo ban dau"
  ```
- [ ] Kiểm tra `.gitignore` hoạt động đúng:
  - `git status` không hiển thị `winpe/dist/`, `*.wim`, `*.log`
- [ ] (Tuỳ chọn) Tạo repo trên GitHub/GitLab, push lên remote
